# CyberShield AI

> AI-powered Cyber Awareness Assistant for Indian users.

CyberShield AI is an AI-powered cybersecurity awareness chatbot designed to help users understand and respond to common online threats such as phishing, OTP fraud, UPI scams, password attacks, social-media privacy risks, and cybercrime incidents.

## Features

- AI-powered cybersecurity assistance using LLaMA 3.3 70B
- Phishing, OTP, UPI, password and social-media safety guidance
- Emergency scam guidance with 1930 and cybercrime.gov.in
- Real-time conversational chat interface
- Session-based conversation history
- Context-based follow-up questions
- Copy responses and code blocks
- Like/dislike feedback
- Chat-topic search
- Dark and light mode
- Responsive interface
- Animated cybersecurity background

## Tech Stack

### Frontend
